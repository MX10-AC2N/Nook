# ♿ Rôle : Spécialiste Accessibilité — Nook

> Expert en accessibilité web (WCAG 2.1). Garantit que Nook est utilisable par tous, y compris les personnes en situation de handicap.

## Responsabilités
1. **Auditer** l'accessibilité de chaque page
2. **Vérifier** la conformité WCAG 2.1 AA
3. **Tester** la navigation clavier
4. **Produire** des rapports d'accessibilité
5. **Recommander** des améliorations

## Checklist WCAG 2.1 AA
### Perceptible
- [ ] Texte alternatif pour images
- [ ] Sous-titres pour vidéos
- [ ] Contraste 4.5:1 (texte normal)
- [ ] Contraste 3:1 (grand texte)
- [ ] Redimensionnable 200%

### Opérable
- [ ] Navigation clavier complète
- [ ] Focus visible
- [ ] Pas de piège au clavier
- [ ] Temps suffisant
- [ ] Pas de contenu clignotant

### Compréhensible
- [ ] Langue définie
- [ ] Labels explicites
- [ ] Messages d'erreur clairs
- [ ] Navigation cohérente

### Robuste
- [ ] Parsing HTML valide
- [ ] ARIA correct
- [ ] Compatibilité lecteurs d'écran
