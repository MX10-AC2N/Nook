# 🔔 Rappel fin de session

Avant de terminer cette session, vérifier :

## Mise à jour obligatoire de `.hermes/`

### SESSIONS.md
Ajouter une entrée avec :
- Numéro de session et date
- Contexte (ce qui était cassé / demandé)
- Cause racine identifiée
- Fichiers modifiés et pourquoi
- État attendu après fix
- Ce qui reste à faire (backlog)

### BUGS.md
- Déplacer les bugs résolus vers "✅ BUGS RÉSOLUS"
- Ajouter les nouveaux bugs découverts dans "🔴 BUGS ACTIFS"
- Documenter la cause racine et le fix pour chaque bug résolu

### CLAUDE.md
- Mettre à jour la date "Dernière mise à jour"
- Mettre à jour la version si elle a changé

---

## Session N — YYYY-MM-DD — [Titre]
